# Planejador de Aula STEM

Aplicação web simples em Flask que permite que professores planejem aulas STEM através de um formulário HTML5.

## Como executar

1. Instale as dependências:

```bash
pip install flask
```

2. Execute a aplicação:

```bash
python app.py
```

A aplicação estará disponível em `http://localhost:5000`.
